# Market Data API

RESTful API сервис для управления финансовыми данными: источниками (биржами), активами (акции, криптовалюты и т.д.) и их котировками. Проект включает автоматический ETL-процесс, который инициализирует базу данных при запуске приложения.

## 🛠 Технологии

* **Язык:** Python 3.12+
* **Фреймворк:** FastAPI
* **ORM & База данных:** SQLAlchemy + SQLite
* **Валидация:** Pydantic V2
* **Тестирование:** Pytest + HTTPX

## 📂 Структура проекта

```text
project/
├── app/
│   ├── __init__.py
│   ├── main.py          # Точка входа FastAPI, настройка lifespan и ETL
│   ├── db.py            # Настройка подключения к SQLite
│   ├── models.py        # SQLAlchemy модели (Source, Asset, Quote)
│   ├── schemas.py       # Pydantic схемы для валидации (Request/Response)
│   └── routes/
│       ├── __init__.py
│       └── market.py    # HTTP-маршруты (CRUD операции)
├── tests/
│   └── test_api.py      # Интеграционные и юнит-тесты
├── etl.py               # Скрипт первоначальной загрузки данных
├── requirements.txt     # Зависимости проекта
└── README.md            # Документация

```

## 🚀 Как запустить проект локально

### 1. Клонирование и настройка окружения

Убедитесь, что у вас установлен Python (рекомендуется версия 3.12). Перейдите в директорию проекта и создайте виртуальное окружение:

```bash
# Создание виртуального окружения
python3 -m venv venv

# Активация (macOS / Linux)
source venv/bin/activate

# Активация (Windows)
venv\Scripts\activate

```

### 2. Установка зависимостей

Установите все необходимые библиотеки из файла `requirements.txt`:

```bash
pip install -r requirements.txt

```

### 3. Запуск сервера

Запустите приложение с помощью Uvicorn. При первом запуске автоматически отработает `etl.py` и создаст локальную базу данных `market_data.db`.

```bash
uvicorn app.main:app --reload

```

Приложение будет доступно по адресу: `http://127.0.0.1:8000`

### 4. Документация API (Swagger UI)

FastAPI автоматически генерирует интерактивную документацию. Перейдите в браузере по ссылке, чтобы тестировать эндпоинты напрямую:
👉 **[http://127.0.0.1:8000/docs](https://www.google.com/search?q=http://127.0.0.1:8000/docs)**

## 🧪 Запуск тестов

В проекте реализованы тесты для проверки всех базовых CRUD-операций и обработки ошибок. Для тестирования используется изолированная база данных `test_market.db`, которая пересоздается при каждом запуске.

Для запуска тестов выполните команду:

```bash
python3 -m pytest tests/test_api.py -v

```

## 📡 Доступные API Эндпоинты

### Sources (Источники/Биржи)

* `GET /sources` — Получить список всех источников.
* `POST /sources` — Создать новый источник.

### Assets (Активы)

* `GET /assets` — Получить список всех активов.
* `GET /assets/{id}` — Получить информацию о конкретном активе.
* `POST /assets` — Добавить новый актив.
* `PUT /assets/{id}` — Полностью обновить данные актива.
* `PATCH /assets/{id}` — Частично обновить данные актива (например, только тикер или валюту).
* `DELETE /assets/{id}` — Удалить актив.

### Quotes (Котировки)

* `GET /assets/{id}/quotes` — Получить историю котировок для конкретного актива.
* `POST /assets/{id}/quotes` — Добавить новую котировку (цену) для актива.
